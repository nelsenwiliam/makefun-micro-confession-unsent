Entry for the [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) bounty on make.fun.

`main.py` (pure Python stdlib, no dependencies) writes one two-part
micro-confession to `entry.txt` in the grader's output directory:

> To: Dad
> You taught me to change a tyre so I'd never need anyone, and I still call you from the hard shoulder because I like hearing you talk me through it.

Run it with `python3 main.py`. It is deterministic: every run writes the
same bytes. The entry is 156 characters in total, inside the 260-character
gate, with the message line at 147 characters, inside its 200-character
limit.
